# Moni

A Markdown editor for local notes that agents can read and edit. Learn more at [moni.md](https://moni.md).

## Download

Moni is available for macOS. Get the DMG from the [latest release](https://github.com/moni-md/moni-releases/releases/latest), or install with Homebrew:

```sh
brew install moni-md/tap/moni
```

Moni keeps itself up to date after you install it.
