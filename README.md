# Moni

A Markdown editor for local notes that agents can read and edit. Learn more at [moni.md](https://moni.md).

## Download

Get the DMG from the [latest release](https://github.com/moni-md/moni-releases/releases/latest), or install with Homebrew:

```sh
brew install moni-md/tap/moni
```

Moni runs on Macs with Apple silicon and macOS 13 or later, and keeps itself up to date.
